Plan de afaceri

Platformă digitală integrată pentru constructori și infrastructură · Model relațional BIM + operațiuni de teren pe Microsoft 365 · Iunie 2026

1. Rezumat executiv

Oferim un portofoliu software dual-layer pentru firme de construcții și infrastructură cu complexitate operațională ridicată: (A) un motor BIM bazat pe graf relațional — model unic din care derivă 3D, planuri, secțiuni, foi de desen și cantități deviz; (B) o platformă de operațiuni de teren nativă SharePoint — urmărire active QR, flotă GPS, planificare echipe, HR și workplace digital. Nu înlocuim Microsoft 365, data warehouse-ul sau PM-ul clientului; le completăm cu date structurate din proiect și de pe șantier. Software funcțional livrat azi, nu doar consultanță.

2. Problema & oportunitatea

Constructorii proiect-intensivi pierd productivitate prin: modele și devize duplicate, lipsă de trasabilitate a uneltelor/plantelor, planificare manuală a echipelor, date izolate între birou și teren. Piața cere digitalizare cu efect măsurabil, integrare M365 și adoptare incrementală — fără „piloturi în groapă". Cererea de dialog strategic (RFI/RFP digital transformation) confirmă nevoia de parteneri cu capacitate de implementare, nu doar strategie.

3. Propunerea de valoare

  • O singură sursă de adevăr pentru geometrie + metadate + BOQ
  • Teren conectat: QR, offline, audit complet hand-out/hand-in
  • M365 first: Azure AD, SharePoint lists, Outlook, Graph API
  • Deschis: IFC, JSON, CSV — fără lock-in
  • AI practic: LLM local (import IFC, query model, asistent inventar)
  • ROI măsurabil: timp deviz, audit active, km/combustibil flotă

5. Piață țintă & clienți

Segment primar: constructori generali și specializați în infrastructură (cale ferată, drumuri, utilități) cu >50 angajați pe teren, M365 deja implementat, data warehouse pentru BI.

Segment secundar: dezvoltatori rezidențiali/comerciali cu deviz propriu (catalog norme RO); birouri BIM regionale.

Buyer personas: Director digital / IT, PMO, șef șantier, QS/devizier, manager flotă/HR, coordonator BIM.

Geografie inițială: România + Nordics/EU — piețe cu norme locale de deviz și maturitate M365.

Trigger de cumpărare: tender cu BOQ accelerat; audit pierderi unelte; conformitate calificări; proiect pilot finanțat din buget digital; dialog strategic cu contractor tier-1.

7. Strategie go-to-market

Faza 1 (0–12 luni): Conversie dialoguri strategice (RFI/RFP) în pilot plătit pe 1 proiect. Demo lite + proof pe cantități F3 și QR tracking. Referințe case study (zidărie confinată, urmărire active).

Faza 2 (12–24 luni): Scale la 3–5 clienți enterprise; parteneriate cu integratori M365; listare pe Azure Marketplace / AppSource (field layer).

Faza 3 (24+ luni): Expansiune catalog norme (EU); legătură deep design↔teren; analytics cross-proiect; canal reseller regional.

Canale: vânzare directă enterprise; parteneri digitali M365; conferințe construcții/infrastructură; content tehnic (BOQ automat, offline QR).

Adoptare client: Discovery 4–6 săpt. → Pilot 8–12 săpt. → Scale 3–6 luni → Operate (SLA). KPI măsurați de la baseline: ore deviz, audit active, compliance calificări.

9. Echipă & operațiuni

Echipă nucleu: architect produs (graf + integrări), specialist BIM (norme, workflow), full-stack (viewere, API), inginer date (ETL warehouse), change manager (training, adopție). Livrare în model hybrid: produs standard + servicii de implementare. Guvernanță: scheme versionate Git, backup proiecte, politică AI local-first, RBAC Azure AD.

11. Riscuri & mitigare

  • Ciclu vânzare lung → pilot plătit, ROI documentat
  • Rezistență la schimbare → lite demo, offline, M365 familiar
  • Gap produs (IFC export, co-editare) → roadmap transparent
  • Concurență incumbent → nișă deviz RO + teren + graf deschis
  • Dependență M365 → API deschis, export JSON/CSV mereu
  • Concentrare client → diversificare SMB + parteneri

12. Concluzie & următorii pași

Combinația model relațional BIM + operațiuni SharePoint acoperă arc-ul complet invitat în dialogul strategic: insight în model, execuție pe teren, date în warehouse. Următorii pași imediați: (1) închidere pilot cu contractor din dialogul de piață; (2) formalizare tier-uri licență; (3) conector ETL pilot spre Power BI; (4) 2 case studies cu KPI măsurați. Obiectiv: partener digital de implementare, nu doar furnizor de slide-uri.
